# AI-продюсер YouTube-канала

Набор инструкций, шаблонов и небольшой скрипт сбора данных. Вы открываете папку в своём агенте (Claude Code, Claude Cowork или Codex) и пишете «запусти месяц». Агент находит залётные видео вашей ниши за 30 дней, разбирает причины по комментариям, предлагает стратегию, месячный план и брифы с упаковкой. **Решает и публикует всегда человек**: проект ничего не публикует и не пишет в YouTube.

Адрес репозитория: `https://github.com/ozerova152-lab/youtube-producer` (заглушка до публикации; кнопка и адрес обновятся при выкладке).

## Быстрый старт

1. **Установите.** В терминале (на Windows сначала откройте WSL):
   ```bash
   git clone https://github.com/ozerova152-lab/youtube-producer.git
   cd youtube-producer
   make setup
   ```
2. **Откройте папку** `youtube-producer` в своём агенте: Claude Code, Claude Cowork или Codex (пути ниже).
3. **Напишите:** «запусти месяц» (в Cowork и Codex: «Прочитай AGENTS.md и запусти месяц»).

Ключ YouTube сейчас не нужен: его можно получить позже, а начать с демо-данных (раздел «Демо без ключа») или с импорта из файла.

## Что понадобится

- компьютер с Linux, macOS или Windows через WSL (на нативном Windows без WSL проект не запускается: откройте WSL и работайте в нём);
- Python 3.12+ с модулем venv, `make`, `git`;
- один из агентов: Claude Code, Claude Cowork или Codex (ИИ-шаги идут по вашей подписке на него; отдельного платного ключа ИИ нет);
- ключ YouTube Data API: бесплатный, но можно начать и без него (см. «Без ключа»).

## Безопасность

Ключ YouTube лежит только в локальном `.env`, не вставляйте его в чат. **Запрет чтения `.env` в `.claude/settings.json` работает только в Claude Code.** В Cowork и Codex ключ держится лишь на инструкции в `AGENTS.md`, поэтому не включайте в них автоподтверждение команд и не вставляйте ключ в чат.

Не включайте автоподтверждение и в Claude Code, и читайте каждый запрос на выполнение команды перед тем, как согласиться. Названия видео и комментарии с YouTube попадают в отчёты, а их читает агент: чужой текст может попытаться уговорить его выполнить лишнее. Запреты в настройках и правила в `AGENTS.md` защищают от случайностей, но не заменяют ваше внимание.

Агент ничего не публикует и не пишет в YouTube; `--confirm` (подтверждение квоты) ставится только после вашего слова; стратегию утверждаете вы правкой файла `strategy.md`.

## Claude Code (проверен полностью)

1. В терминале: `cd youtube-producer`, затем `claude`.
2. Напишите: **«запусти месяц»**.
3. Вернуться к месту остановки: **«продолжи месяц»**.

Необязательный бонус: мини-скиллы `/start-month`, `/continue-month`, `/demo`, `/setup-check` (описаны в `CLAUDE.md`). Без них всё работает по фразам.

Пометка: **проверено** (инструкции на демо-данных и записанных ответах YouTube; настоящий сбор по ключу).

## Claude Cowork (если нет Claude Code)

1. На странице репозитория на GitHub нажмите Code → Download ZIP (адрес выше, пока заглушка).
2. Распакуйте архив.
3. Откройте распакованную папку в Claude Cowork. По справке Anthropic для работы с локальной папкой нужно приложение Claude Desktop; как именно добавить папку в сессию, смотрите в интерфейсе (названия пунктов мы не сверяли).
4. Напишите агенту дословно: **«Прочитай AGENTS.md и запусти месяц»**. Вернуться: **«Прочитай AGENTS.md и продолжи месяц»**.
5. Ключ YouTube: скопируйте шаблон `.env.example` в `.env` и впишите ключ в этот локальный файл (получение ключа: разделы 1 и 2 ниже). Без ключа выберите импорт из файла: формат в [docs/import-format.md](docs/import-format.md).

**Проверено:**

- инструкции и сценарии на демо-данных и записанных ответах YouTube;
- команды скрипта (`produce`);
- тесты проекта (`make check`).

**Не проверено:**

- запуск именно в Claude Cowork;
- умеет ли Cowork в вашей среде запускать команды скрипта (Python, `make`): не обещаем, посмотрите сами;
- читает ли он `AGENTS.md` сам;
- настоящий сбор по ключу проверен в Claude Code, в Cowork не проверен.

**Про ключ.** Запрет чтения `.env` на уровне настроек (`.claude/settings.json`) работает только в Claude Code. В Cowork он держится лишь на инструкции в `AGENTS.md`, поэтому проверьте сами, что агент ключ не показывает, и не вставляйте его в чат, и не включайте автоподтверждение команд (подробнее в «Безопасность»).

**Главное, как и везде:** агент ничего не публикует и не пишет в YouTube; `--confirm` (подтверждение квоты) ставится только после вашего слова; стратегию утверждаете вы правкой файла `strategy.md`.

## Codex

Отдельной поддержки Codex нет. Установите и откройте его в папке проекта: `cd youtube-producer`, затем `codex` (по документации OpenAI на странице Codex CLI; приложение Codex со способом открытия папки мы не сверяли). Либо дайте ему ссылку на репозиторий. Документация OpenAI говорит, что Codex сам читает `AGENTS.md` перед работой, но на всякий случай пишите дословно: **«Прочитай AGENTS.md и запусти месяц»**; вернуться: **«Прочитай AGENTS.md и продолжи месяц»**.

Честная пометка: **Codex проверен лишь на базовом уровне**, остальное, включая паузы агента, в нём не проверялось. Запрет чтения `.env` здесь держится только на инструкции (см. «Безопасность»).

## Демо без ключа и без сети

Тестовый канал лежит в `examples/demo/`. Ничего платного и никаких правок кода:

```bash
cp -r examples/demo data/demo
.venv/bin/produce --channel data/demo start --segment ru --brief-lang ru
.venv/bin/produce --channel data/demo import examples/demo/import_comments.json --segment ru
.venv/bin/produce --channel data/demo virals --segment ru
```

Что должно получиться: `import` пишет «Загружено: 11 видео, 2 канала. Обращений к YouTube: 0», `virals` находит 2 залёта (например, «Как использовать нейросеть: выпуск 1», ×12.68 к норме канала). В файле `import_comments.json` есть комментарии, поэтому на шаге разбора агент показывает причины по комментариям, а не догадки по названиям. Дальше напишите агенту «запусти месяц» на канале `data/demo`. Сбросить: `make reset`. Если `data/demo` уже есть, `cp` положит копию внутрь неё: сначала `make reset`.

## 1. Ключ YouTube Data API (бесплатно)

Квота бесплатная: 10 000 единиц в день, типичному месяцу хватает с запасом. Платить ничего не нужно, банковская карта не требуется.

Кратко: в [Google Cloud Console](https://console.cloud.google.com/) создайте проект, включите **YouTube Data API v3**, создайте ключ API и ограничьте его (только YouTube Data API v3; «Application restrictions» оставьте None). Кнопку «Start free» не нажимайте.

**Подробная пошаговая инструкция для новичка: [docs/api-key-guide.md](docs/api-key-guide.md).**

## 2. Куда положить ключ

Ключ лежит только в локальном файле `.env` в корне проекта. Он не попадает в git (внесён в `.gitignore`).

```bash
cp .env.example .env
# откройте .env и впишите: YOUTUBE_API_KEY=ваш_ключ
```

Не вставляйте ключ в чат. Команды с полными путями и проверкой, что файл создан, — в разделе «Шаг 5» [инструкции](docs/api-key-guide.md). Агент `.env` не читает и ключ не показывает. Если ключ где-то засветился (чат, коммит, экран), перевыпустите его в Google Cloud: удалить недостаточно.

## 3. Установка

```bash
git clone https://github.com/ozerova152-lab/youtube-producer.git
cd youtube-producer
make setup
```

`make setup` создаёт `.venv` и ставит зависимости для запуска. Браузер Chromium (около 120 МБ) не скачивается: он нужен только разработчику для проверки страницы-витрины (`make setup-dev`, см. `docs/dev/setup.md`).

На Windows: сначала откройте WSL, все команды выполняйте в нём.

## 4. Первый запуск

1. Откройте папку проекта в своём агенте (пути выше).
2. Напишите агенту: **«запусти месяц»** (в Cowork и Codex: «Прочитай AGENTS.md и запусти месяц»).
3. Агент спросит про настройки канала. Если файла нет, он покажет образец `examples/demo/settings.yaml`: скопируйте его в `data/<канал>/settings.yaml`, заполните нишу, сегменты и слова, напишите «готово».
4. Выберите сегмент и язык брифа.
5. Агент покажет **оценку квоты** (например, «Расход: ~430 из 10 000 единиц… Запускаем сбор?») и остановится. Сбор начнётся только после вашего «да».

Дальше агент идёт по шагам: залёты, разбор причин, ниша, стратегия. Стратегию он пишет черновиком и **останавливается**: если вы согласны, замените в `strategy.md` статус на «утверждена» и напишите «готово». Потом он делает брифы, а вы ставите в каждом статус «принят», «отклонён» или «позже»; из принятых собирается месячный план. Вернуться к месту остановки: «продолжи месяц».

Посмотреть всё на тестовых данных, ничего не тратя: раздел «Демо без ключа и без сети».

## Без ключа: импорт из файла

Если ключа нет, агент предложит выбрать: получить ключ или загрузить видео из файла CSV/JSON. Файл вы готовите сами. Формат колонок описан в [docs/import-format.md](docs/import-format.md), образец — `examples/demo/import.csv`. Импорт не ходит в сеть, квоту не тратит и подтверждения не требует:

```bash
.venv/bin/produce --channel data/<канал> import путь/к/файлу.csv
```

Без комментариев в файле причины залётов будут предположительными (по названиям и описаниям).

## Если что-то не получилось

| Что видите | Что сделать |
|-----------|-------------|
| `make: command not found` или `python3: command not found` | Поставьте `make` и Python 3.12+ с модулем venv (Ubuntu/WSL: `sudo apt install -y make python3-venv python3-pip`). `python3 --version` должен показать 3.12 или новее |
| `make setup` упал, в тексте «ensurepip is not available» | `sudo apt install python3-venv`, затем снова `make setup` |
| `make setup` упал с «No space left on device» | Освободите место на диске и повторите `make setup`; если успело создаться `.venv`, удалите его (`rm -rf .venv`) |
| «Ключ не подошёл (YouTube отклонил)…» | Ключ в `.env` с опечаткой, не тот или ограничен не тем сервисом. Перепроверьте по [инструкции](docs/api-key-guide.md); если ключ где-то засветился, перевыпустите его |
| «Квота на сегодня закончилась. Собрано N%, прогресс сохранён. Продолжите завтра» | Это не поломка: подождите до следующих суток по времени Google и напишите «продолжи месяц» |
| Агент не понимает фразу или отвечает не по сценарию | Проверьте, что открыта именно папка проекта (в ней лежит `AGENTS.md`). В Cowork и Codex пишите с началом «Прочитай AGENTS.md и …» |
| «Не найден файл настроек» | Нужен `data/<канал>/settings.yaml`: скопируйте образец `examples/demo/settings.yaml` (агент подскажет) |

## Слова, которые встретятся

- **Залёт** — видео, у которого просмотров заметно больше обычного для канала.
- **Норма канала** — типичные просмотры роликов этого канала; залёт сравнивают с ней («×12.68» — во столько раз выше).
- **Квота** — дневной лимит обращений к YouTube (10 000 единиц, бесплатно); перед сбором агент показывает расход.
- **Сегмент** — пара «регион + язык» в `settings.yaml` (например, ru и en); месяц идёт по одному сегменту.
- **Бриф** — задание на одно видео с названием и упаковкой; вы ставите ему статус «принят», «отклонён» или «позже».
- **Стратегия** — черновик, который агент пишет по найденному; дальше он ждёт, пока вы поставите «утверждена».
- **Запуск** — одна работа за месяц по сегменту, её файлы лежат в `data/<канал>/runs/`.
- **WSL** — Linux внутри Windows; на Windows проект запускается только в нём.

## Сколько времени и подписки уходит

- Расход квоты в оценке для образца `examples/demo` (сегмент ru): «~431 из 10 000 единиц (3 поиска, 114 запросов)». Это оценка до сбора, обращений к сети при ней 0.
- Демо без ключа: 0 обращений к YouTube, квота не тратится.
- Время реального запуска месяца: не измерено.
- Расход подписки агента (Claude Code, Cowork, Codex): не измерен.

## Что внутри

- `AGENTS.md` — общая инструкция агента для Claude Code, Cowork и Codex; `CLAUDE.md` подключает её и держит только то, что работает в Claude Code; `playbooks/` — сценарии по шагам, начиная с `playbooks/00-month.md`;
- `templates/` — образцы файлов (стратегия, брифы, план); `examples/demo/` — тестовый канал и образцы результатов;
- `src/produce/` — скрипт сбора данных (`produce`); `site/` — страница-витрина.

Проверка при разработке: `make setup-dev`, затем `make check` (поиск секретов, линтер, тесты на записанных ответах YouTube; ключи и сеть не нужны).
