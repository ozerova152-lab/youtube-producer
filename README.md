# AI-продюсер YouTube-канала

Помощник, который находит видео вашей темы, набравшие много просмотров, объясняет почему и предлагает, что снять.

Адрес репозитория: `https://github.com/ozerova152-lab/youtube-producer`. Страница-витрина: <https://ozerova152-lab.github.io/youtube-producer/>.

## Что вы получите

За один «месяц» работы на вашем компьютере появятся файлы (в `data/<канал>/runs/<месяц>_<сегмент>_v<N>/`):

- список **залётов**: видео вашей ниши за 30 дней, у которых просмотров намного больше обычного, и ваши лучшие и слабые ролики (`report.md`);
- разбор: почему они «выстрелили», по комментариям зрителей (`analysis.md`), и необязательный разбор обложек (`covers.md`);
- ниша и кандидаты в конкуренты, затем **стратегия**: о чём и в каком формате снимать (`strategy.md`); агент пишет черновик, утверждаете вы;
- **брифы** (задание на одно видео: название, обложка, структура) и план на месяц (`briefs/`, `plan.md`);
- `00-overview.md`: обзор всех файлов запуска, с него удобно начать.

Проект ничего не публикует и не пишет в YouTube. Решаете и выкладываете вы.

## Что понадобится

- Компьютер с Windows, macOS или Linux. На Windows один раз ставится WSL (Linux внутри Windows, 20–30 минут).
- ИИ-агент: программа-помощник, которой вы пишете по-русски ([список и статус](docs/compatibility.md)). Нужна подписка на него. Отдельных платных ключей ИИ у проекта нет.
- Python 3.12 или новее, `git` и `make`: на шагах 2–3 покажу, как проверить.
- Ключ YouTube понадобится позже. Начать можно без него.
- Только обычный чат с ИИ, где нельзя запускать программы? Ничего ставить не нужно: [режим чата](docs/chat-mode.md).

## Быстрый старт

**Терминал** — окно, куда печатают команды вместо кликов мышью. Mac: Cmd+Пробел, наберите «Терминал». Linux: Ctrl+Alt+T. Windows: «Пуск» → Ubuntu (после шага 1). Команду копируйте целиком, вставляйте (в терминале обычно Ctrl+Shift+V) и нажимайте Enter.

### Шаг 1. Только Windows: поставьте WSL

**Что сделать:** пройдите [инструкцию по WSL](docs/windows-wsl.md) (один раз). На Mac и Linux пропустите шаг.
**Что увидите:** чёрное окно Ubuntu, в начале строки что-то вроде `anna@pc:~$`.
**Если не получилось:** в начале строки `PS C:\…`, значит вы в PowerShell, а не в Ubuntu. Откройте Ubuntu из «Пуска». Остальное: «Если застряли» в конце инструкции.

### Шаг 2. Скачайте проект

**Что сделать:** в терминале выполните две команды: `git clone https://github.com/ozerova152-lab/youtube-producer.git`, затем `cd youtube-producer`.
**Что увидите:** слова «Cloning…» и возврат к строке ввода. Команда `ls` покажет файлы, среди них `AGENTS.md`.
**Если не получилось:** «git: command not found». На Ubuntu выполните `sudo apt install -y git`. На Mac терминал предложит поставить инструменты разработчика: согласитесь и повторите команду.

### Шаг 3. Проверьте Python и подготовьте проект

**Что сделать:** сначала узнайте версию Python (языка, на котором написан скрипт проекта): выполните `python3 --version`. Затем выполните `make setup`: команда сама скачает всё нужное (нужен интернет, это может занять несколько минут).
**Что увидите:** на первую команду ответ вида `Python 3.12.3`: подходит число 3.12 или больше (3.13 тоже годится). Вторая команда выводит бегущие строки установки; в конце нет слова «Error».
**Если не получилось:**

- Версия ниже 3.12 (например, `Python 3.9.6`). **Mac:** встроенный Python старый. Откройте <https://www.python.org/downloads/>, скачайте установщик Python 3.12 или новее, запустите его (кнопки «Продолжить» до конца), закройте терминал, откройте новый и снова выполните `python3 --version`: должно быть 3.12 или больше. **Ubuntu:** нужна более новая Ubuntu (24.04 приходит сразу с Python 3.12); на Windows это `wsl --install -d Ubuntu-24.04`, подробнее в [инструкции по WSL](docs/windows-wsl.md).
- «python3: command not found» или «make: command not found». Ubuntu: `sudo apt install -y make python3-venv python3-pip`. Mac: `make` придёт вместе с инструментами разработчика (см. шаг 2), Python ставится с python.org, как выше. Потом снова `make setup`.
- Другие случаи: [таблица ниже](#если-что-то-не-получилось).

### Шаг 4. Откройте папку в агенте

**Что сделать:** в этой же папке запустите агента: `claude` (Claude Code) или `codex` (Codex). Для Claude Cowork откройте папку проекта в приложении Claude Desktop.
**Что увидите:** окно ввода агента, куда можно писать.
**Если не получилось:** агента нет на компьютере или нет подписки на него: проект без агента не работает. Как запускать каждого: [агенты](docs/compatibility.md).

### Шаг 5. Скажите фразу

**Что сделать:** напишите агенту: «Прочитай AGENTS.md и запусти месяц».
**Что увидите:** агент скажет, как будет работать, и спросит про ваш канал. Дальше он ведёт вас сам и на каждой остановке ждёт вашего слова («да», «готово», «утверждена»).
**Если не получилось:** агент отвечает не по делу. Проверьте, что открыта именно папка `youtube-producer` (в ней лежит `AGENTS.md`), и начинайте фразу с «Прочитай AGENTS.md и…».

Вернуться к месту остановки после паузы: «Прочитай AGENTS.md и продолжи месяц».

## Попробовать без ключа

Тестовый канал уже лежит в проекте. Ничего платного, интернет не нужен. Выполните по порядку три команды:

```bash
mkdir -p data && cp -r examples/demo data/demo && .venv/bin/produce --channel data/demo start --segment ru --brief-lang ru
.venv/bin/produce --channel data/demo import examples/demo/import_comments.json --segment ru
.venv/bin/produce --channel data/demo virals --segment ru
```

Что должно получиться: вторая команда пишет «Загружено: 11 видео, 2 канала. Обращений к YouTube: 0», третья находит 2 залёта (например, «Как использовать нейросеть: выпуск 1», ×12.68 к норме канала). Если `data/demo` уже есть, сначала `make reset`. Дальше можно написать агенту «Прочитай AGENTS.md и запусти месяц» на канале `data/demo`.

## Свой канал

Начать можно двумя путями.

**Ключ YouTube Data API.** Он бесплатный (10 000 единиц квоты в день, карта не нужна). Пошаговая инструкция для новичка: [docs/api-key-guide.md](docs/api-key-guide.md). Кратко: в [Google Cloud Console](https://console.cloud.google.com/) создайте проект, включите YouTube Data API v3, создайте ключ и ограничьте его только этим API («Application restrictions» оставьте None); кнопку «Start free» не нажимайте. Записать ключ проще всего командой, текстовый редактор не нужен: в обычном терминале (в Windows это окно Ubuntu, не чат с агентом) в папке проекта выполните `make add-key`. Она спросит ключ (при вводе ничего не видно, это нормально), сама создаст `.env` только для вас и ничего не покажет. Не вставляйте ключ в чат. Другой способ, если привыкли править файл руками: выполните `cp .env.example .env`, откройте `.env` в любом текстовом редакторе и впишите строку:

```
YOUTUBE_API_KEY=ваш_ключ
```

Агент `.env` не читает и ключ не показывает. После записи скажите агенту «ключ добавил».

**Файл вместо ключа.** Подготовьте таблицу видео в формате CSV/JSON (колонки: [docs/import-format.md](docs/import-format.md), образец: `examples/demo/import.csv`). Загрузка идёт без сети и без квоты:

```bash
.venv/bin/produce --channel data/<канал> import путь/к/файлу.csv
```

Без комментариев в файле причины залётов будут предположительными (по названиям и описаниям).

## Если что-то не получилось

| Что видите | Что сделать |
|-----------|-------------|
| `make setup` падает, а `pwd` начинается с `/mnt/c` | Проект лежит на диске Windows. Скопируйте его в домашнюю папку Ubuntu ([как](docs/windows-wsl.md)) и запустите `make setup` там |
| `make setup` упал, в тексте «ensurepip is not available» | `sudo apt install python3-venv`, затем снова `make setup` |
| `make setup` упал с «No space left on device» | Освободите место и повторите; если успел создаться `.venv`, удалите его (`rm -rf .venv`) |
| «Ключ не подошёл (YouTube отклонил)…» | Опечатка в ключе или ключ не того сервиса. Перепроверьте по [инструкции](docs/api-key-guide.md); если ключ где-то засветился, перевыпустите его |
| «Квота на сегодня закончилась… Продолжите завтра» | Это не поломка: подождите до следующих суток по времени Google и напишите «продолжи месяц» |
| Агент просит обложки или не понимает фразу | Обложки: [агенты](docs/compatibility.md#обложки-залётов-шаг-3б). Фраза: откройте именно папку проекта и начинайте с «Прочитай AGENTS.md и…» |
| «Не найден файл настроек» | Нужен `data/<канал>/settings.yaml`: скопируйте образец `examples/demo/settings.yaml` (агент подскажет) |
