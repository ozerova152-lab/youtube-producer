Расскажите, как получилось

Как это работает

  1. Первый запуск. Поставить репозиторий, настроить канал, дойти до оценки квоты (или импорта).
  2. Сбор и залёты. Подтвердить квоту, собрать данные, увидеть залёты и свои результаты, получить разбор причин.
  3. Ниша и стратегия. Понять нишу, получить кандидатов и утвердить стратегию.
  4. Брифы и план. Получить брифы, решить по каждому, получить месячный план.
  5. Новый месяц. Запустить следующий месяц без повторов отклонённого, вернуть брифы «позже».

Решает и публикует всегда человек.

Если что-то не получилось

Я на Windows

Если вы запускаете Claude Code или Codex на Windows, один раз нужно поставить WSL: это Linux внутри Windows, один разовый шаг, около 20–30 минут. Для работы в обычном чате WSL не нужен.

Агент сам WSL не ставит: нужны права администратора и перезагрузка, он расскажет шаги и подождёт. Подробная инструкция по шагам — в инструкции по WSL.

Не хотите разбираться сами? Скажите любому ИИ-агенту: «Я на Windows и ничего не понимаю в терминале. Помоги поставить WSL и дойти до запуска проекта, объясняй каждый шаг».

Если застряли:

  • Пароль при вводе не показывается: это нормально, просто введите его и нажмите Enter.
  • Если wsl --install пишет про виртуализацию, на некоторых компьютерах её нужно включить в BIOS.
  • Вы в окне Ubuntu, если в начале строки стоит имя@компьютер. Если там PS C:\...>, это PowerShell: откройте Ubuntu из меню «Пуск».
Не хватает Python, make или git

Это маленькие программы, без которых проект не запускается: Python запускает скрипт, git скачивает проект, make запускает готовые команды. Агент скажет, чего не хватает, и подскажет команду. Команды с паролем администратора вводите сами: агент пароль не знает.

Хочу поставить сам, по шагам
  1. Скачайте проект: на странице репозитория нажмите Code → Download ZIP и распакуйте архив. Один раз в терминале внутри папки выполните make setup: эта команда сама скачает всё нужное для работы (нужен интернет).
  2. Откройте папку проекта в вашем агенте (подсказки ниже).
  3. Скажите агенту: «Прочитай AGENTS.md и запусти месяц».

Откройте терминал в папке проекта и запустите claude.

У меня только чат, без терминала

Установка не нужна. Дайте чату файл AGENTS.md и напишите «запусти месяц»: любые данные о видео (таблицу, файл, выгрузку) вы вставляете в чат, результаты чат присылает текстом.

Как открыть терминал

Терминал — окно, куда печатают команды вместо кликов мышью. Mac: Cmd+Пробел и слово «Терминал». Linux: Ctrl+Alt+T. Windows: «Пуск» и Ubuntu (после установки WSL).

Пример результата

Бриф 1: Нейросеть для таблиц без формул

Вид
Длинное видео, 10–12 минут.
Идея
Показать новичку, как бесплатная нейросеть собирает рабочую таблицу из обычной просьбы словами: без формул и без страха сломать файл.
Чем отличаемся
Залёт «Как использовать нейросеть: выпуск 1» объяснял, как написать нейросети письмо; мы берём следующий шаг, о котором просили зрители в комментариях (таблицы), и делаем один рабочий пример, а не обзор сервисов.
Первые 15 секунд
«Вот таблица расходов за месяц. Я не написал в ней ни одной формулы. Сейчас покажу, как это сделала бесплатная нейросеть, и вы повторите за десять минут». На экране сначала готовая таблица, затем пустой лист.
Название 1
Нейросеть собрала мне таблицу за 5 минут: без формул
