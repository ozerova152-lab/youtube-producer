AI-продюсер YouTube-канала

Находит залётные видео вашей ниши, разбирает причины и готовит стратегию, план и брифы. Решает и публикует всегда человек.

Скачать на GitHub

Как это работает

  1. Первый запуск. Поставить репозиторий, настроить канал, дойти до оценки квоты (или импорта).
  2. Сбор и залёты. Подтвердить квоту, собрать данные, увидеть залёты и свои результаты, получить разбор причин.
  3. Ниша и стратегия. Понять нишу, получить кандидатов и утвердить стратегию.
  4. Брифы и план. Получить брифы, решить по каждому, получить месячный план.
  5. Новый месяц. Запустить следующий месяц без повторов отклонённого, вернуть брифы «позже».

Решает и публикует всегда человек.

Как запустить

Запускать проект нужно на компьютере. Скопируйте адрес репозитория, чтобы открыть его там.

  1. Скачайте проект: на странице репозитория нажмите Code → Download ZIP и распакуйте архив. Один раз в терминале внутри папки выполните make setup: эта команда сама скачает всё нужное для работы (нужен интернет).
  2. Откройте папку проекта в вашем агенте (подсказки ниже).
  3. Скажите агенту: «Прочитай AGENTS.md и запусти месяц».

На Windows терминал открывайте в WSL: это Linux внутри Windows, без него проект не запустится.

В Claude Code

Откройте терминал в папке проекта и запустите claude.

В Claude Cowork

Откройте папку проекта в приложении Claude Desktop.

В Codex

Дайте Codex ссылку на репозиторий и напишите: «Изучи youtube-producer и помоги начать».

Основной путь — Claude Code, проверен полностью. Codex проверен на реальном канале (30.10.2026) от установки до брифов: установка, ключ, сбор данных, залёты, ниша и кандидаты, стратегия, брифы. Cowork мы не проверяли: используйте тот же AGENTS.md и пишите в Issues.

Нет ключа YouTube? Можно загрузить видео из файла.

Пример результата

Бриф 1: Нейросеть для таблиц без формул

Вид
Длинное видео, 10–12 минут.
Идея
Показать новичку, как бесплатная нейросеть собирает рабочую таблицу из обычной просьбы словами: без формул и без страха сломать файл.
Чем отличаемся
Залёт «Как использовать нейросеть: выпуск 1» объяснял, как написать нейросети письмо; мы берём следующий шаг, о котором просили зрители в комментариях (таблицы), и делаем один рабочий пример, а не обзор сервисов.
Первые 15 секунд
«Вот таблица расходов за месяц. Я не написал в ней ни одной формулы. Сейчас покажу, как это сделала бесплатная нейросеть, и вы повторите за десять минут». На экране сначала готовая таблица, затем пустой лист.
Название 1
Нейросеть собрала мне таблицу за 5 минут: без формул

Пример на демо-данных, не реальный канал.
