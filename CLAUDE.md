# Только Claude Code

Правила агента и правила разработки лежат в `AGENTS.md` (подключён строкой выше). Здесь только то, что работает в Claude Code и больше нигде.

## Защита ключа в настройках

Запрет чтения `.env` и правки `settings.yaml` записан в `.claude/settings.json` (раздел `permissions.deny`) и действует на уровне программы, а не только инструкции. В Cowork и Codex такой защиты нет: там ключ держится на правиле из `AGENTS.md`.

## Мини-скиллы (необязательный бонус)

Лежат в `.claude/skills/`. Без них всё работает по фразам из `AGENTS.md`.

| Скилл | Что делает |
|-------|-----------|
| `/start-month` | то же, что фраза «запусти месяц» |
| `/continue-month` | то же, что фраза «продолжи месяц» |
| `/demo` | копирует `examples/demo` в `data/demo` (существующую не затирает) и объясняет вывод |
| `/setup-check` | проверяет Python, `make`, `.venv` и только наличие `.env` (содержимое не читает) |
| `/check` | `make check` |
| `/reset` | `make reset` |
