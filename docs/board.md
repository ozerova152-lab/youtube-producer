# Локальная доска YouTube Producer

Доска открывается в браузере на вашем компьютере. Она показывает файлы выбранного канала и запуска и сохраняет ваши решения рядом с ними. ИИ-агент остаётся в Codex или Claude Code: после решения на доске вернитесь к нему и напишите «продолжи месяц», указав канал, сегмент и имя запуска с доски. Кнопка сама ИИ не запускает.

## Как установить и запустить

Откройте проект и попросите агента: «Помоги установить YouTube Producer и открыть доску». Сначала следуйте обычной установке в README. Если используется Windows, проект рекомендуется держать в домашней папке Ubuntu/WSL; адрес выглядит как `/home/<имя>/youtube-producer`, это локальные файлы на вашем компьютере. Их можно открыть в VS Code через WSL. В вашем проекте работа может лежать в другой папке — её адрес покажет агент.

После установки из корня проекта запустите `.venv/bin/python -m produce.board --data-root data`. Программа покажет локальный адрес; откройте его в браузере. Окно терминала с работающим сервером оставьте открытым. Остановить доску можно клавишами Ctrl+C в нём; файлы проекта сохранятся.

Для знакомства скажите агенту «Подготовь демонстрационный канал для доски». Он использует только локальный пример без YouTube, ключа и сети. Существующий демонстрационный канал не перезаписывается. Вместо примера можно выбрать уже настроенный вами канал; до появления результатов вкладки честно покажут, каких данных нет.

## Как работать

Выберите канал и запуск. Просмотрите вкладки «Идеи», «Конкуренты», «Ниша», «Аналитика ниши», «Контент-план» и «Видео». Если доска сообщает, что данные изменились, обновите её и повторите выбор: это защищает от перезаписи. Не редактируйте один файл одновременно в стороннем редакторе и на доске: согласованный механизм защиты работает для доски и сценариев проекта.

После утверждения стратегии агент предложит идеи. Нажмите для каждой «Принять», «Отклонить» или «Позже». Вернитесь к агенту, сообщите канал, сегмент и запуск и напишите «продолжи месяц». Он подготовит брифы и сценарии только по принятым идеям. После этого вы отдельно проверите и утвердите готовые брифы для плана. Старые брифы остаются доступными, а их статусы вы можете менять через доску.

Для данных YouTube нужен ваш собственный ключ Google YouTube Data API. Значение вводите сами через `make add-key` в обычном терминале, не присылайте его агенту или в чат. Перед сбором будет показана оценка квоты и запрошено подтверждение. Демо и импорт из файла не требуют ключа. Проект не публикует видео и не пишет в YouTube от вашего имени.

## Где проект и как поделиться

Вы владеете своей установленной копией и можете дорабатывать проект. Его лицензия MIT разрешает другим людям использовать и изменять копии на условиях в файле `LICENSE`; это не даёт им права менять ваш GitHub-репозиторий без доступа. Другому человеку можно дать ссылку на публичный [YouTube Producer](https://github.com/ozerova152-lab/youtube-producer): он получит собственную копию и настроит свой канал. Персональные результаты в `data/` и ключи в `.env` не входят в Git и не должны отправляться на GitHub. Локальная папка и GitHub обновляются отдельно.
