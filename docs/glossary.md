# Слова, которые встретятся

[← К README](../README.md)

- **Терминал** — окно, куда печатают команды вместо кликов мышью.
- **Агент** — ИИ-помощник, которому вы пишете по-русски (Claude Code, Codex, Claude Cowork); он читает `AGENTS.md` и ведёт вас по шагам.
- **Залёт** — видео, у которого просмотров заметно больше обычного для канала.
- **Норма канала** — типичные просмотры роликов этого канала; залёт сравнивают с ней («×12.68» — во столько раз выше).
- **Квота** — дневной лимит обращений к YouTube (10 000 единиц, бесплатно); перед сбором агент показывает расход.
- **Сегмент** — пара «регион + язык» в `settings.yaml` (например, ru и en); месяц идёт по одному сегменту.
- **Бриф** — задание на одно видео с названием и упаковкой; вы ставите ему статус «принят», «отклонён» или «позже».
- **Стратегия** — черновик, который агент пишет по найденному; дальше он ждёт, пока вы поставите «утверждена».
- **Запуск** — одна работа за месяц по сегменту, её файлы лежат в `data/<канал>/runs/`.
- **WSL** — Linux внутри Windows; на Windows проект запускается только в нём ([как поставить](windows-wsl.md)).
