# Локальное окружение — AI-продюсер YouTube-канала

> Как поднять проект и как им пользоваться · Дата: 2026-10-22
> Основа: docs/spec/02-tech-architecture.md, docs/spec/03-dev-architecture.md

## Что должно стоять на компьютере

| Инструмент | Зачем | Проверка |
|-----------|-------|----------|
| Python ≥ 3.12 с модулем venv | Язык и изолированное окружение | `python3 --version` |
| make | Запуск команд проекта одним словом | `make --version` |
| gitleaks | Поиск случайно попавших ключей | `gitleaks version` |
| git, gh | История и GitHub | `git --version`, `gh auth status` |

В Ubuntu: `sudo apt install -y make python3-venv python3-pip gitleaks`.

## Поднять одной командой

- `make setup` — создаёт `.venv` и ставит зависимости.
- `make check` — поиск секретов, линтер, тесты; ключи, сеть и деньги не нужны.
- `.venv/bin/produce --channel examples/demo` — запуск на тестовом канале; показывает канал и сегменты. Остальные шаги (`collect`, `strategy`, `briefs`, `plan`) появятся на этапе разработки.
- Остановка не нужна: фоновых сервисов нет.

## Папки инструкций

- `playbooks/` — сценарии шагов для агента (Markdown), `templates/` — образцы файлов; наполняются на этапе разработки.
- Главный файл инструкций агента один — `CLAUDE.md`.
- Запрет чтения `.env` для Claude Code — в `.claude/settings.json` (только Claude Code).

## Тестовые данные

- `examples/demo/settings.yaml` — тестовый канал с двумя сегментами (ru, en), без конкурентов, с порогами по умолчанию.
- Записанные ответы YouTube («кассеты») появятся на этапе разработки.
- Сброс в чистое состояние: `make reset` (или мини-скилл `/reset`) — удаляет `data/demo`.

## Мини-скиллы (только Claude Code)

Это удобство для Claude Code; те же команды записаны текстом в `CLAUDE.md` и работают в любом агенте.

| Скилл | Что делает | Статус |
|-------|-----------|--------|
| `/check` | `make check`: все автопроверки | готов |
| `/reset` | `make reset`: сброс тестового канала | готов; пересоздание демо-данных после сброса добавится на этапе разработки |

Настоящий прогон на реальных ключах мини-скиллом не делается: только вручную, после оценки квоты и вашего «да».

## Реальные ключи (для ручного прогона)

Автопроверки идут на записанных данных — ключи не нужны. Для реального режима нужен только ключ YouTube; ИИ-шаги выполняет ваш Claude Code по вашей подписке, отдельного ключа ИИ нет:

| Ключ | Где взять | Куда положить |
|------|-----------|---------------|
| `YOUTUBE_API_KEY` | Google Cloud Console → YouTube Data API v3 → Credentials | `.env` (по образцу `.env.example`) |

- Ключ YouTube бесплатный (квота 10 000 единиц в день); ограничьте его в Google Cloud только YouTube Data API v3.
- Ключ засветился (в коммите, чате, на экране) → **перевыпустите** его в Google Cloud; удалить из кода недостаточно.

## Частые проблемы

- `python3 -m venv` падает с «ensurepip is not available» → `sudo apt install python3-venv`.
- `make check` ругается на найденный ключ → убрать его из файла, перевыпустить ключ, только потом коммитить.
