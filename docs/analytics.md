# Аналитика продукта

Обновлено: 2026-10-30 · Планировал: /plan-analytics · Отчёты: /analytics-report

Контекст. Проект работает на компьютере каждого человека, своих серверов, базы и пользователей у него нет. Измерить снаружи можно только интерес к репозиторию, посещение витрины и здоровье сборки. Что делает продукт у людей, мы не видим и видеть не должны: данные канала приватные, в спеке обещано, что ничего наружу не уходит. Бюджет 0 ₽ (слой 2 спеки).

## 1. Вопросы, на которые отвечаем

Приоритет, который выбрал человек: интерес к проекту; здоровье сборки второе.

| Вопрос | Метрика | Что сделаю, узнав ответ |
|---|---|---|
| Интересуются ли проектом люди кроме меня? | просмотры и уникальные посетители репозитория, клоны, звёзды, форки | нет интереса: пишу о проекте там, где живёт аудитория (в спеке она в основном российская); есть: смотрю, что читают |
| Откуда приходят? | источники переходов GitHub (`referrers`), популярные страницы (`paths`) | усиливаю тот канал, откуда приходят |
| Работает ли публикация витрины и проверки? | упавшие запуски GitHub Actions, открытые pull request Dependabot | чиню в тот же день / разбираю обновления раз в неделю |

Строка без решения в третьей колонке в карту не входит. Вопросы сформулированы по выбору человека; человек может их поправить.

## 3. Воронка интереса

1. Увидел ссылку или страницу → источник: `traffic/popular/referrers` (пока пусто).
2. Открыл репозиторий → `traffic/views`.
3. Скопировал проект → `traffic/clones` (содержит и мои клоны, отделить нельзя).
4. Поставил звезду или форк → поля `stargazers_count`, `forks_count`.

Витрина (`https://ozerova152-lab.github.io/youtube-producer/`) в воронку не входит: посещения не считаются.

## 4. Здоровье

| Что | Где смотреть | Что считаем тревогой |
|---|---|---|
| Публикация витрины | `gh run list --workflow Pages --limit 10` | любой `failure` после включения Pages |
| Проверки и зависимости | локально `make check`, `make audit` | красный `make check`, найденные уязвимости |
| Обновления зависимостей | `gh pr list --state open` (pull request от Dependabot) | больше недели без разбора |
| Квота у человека | `quota_spent`, `requests_count` в `run.json` запуска | только локально, наружу не уходит и в отчёты не попадает |

## 5. Где брать данные

| Среда | Источник | Доступ |
|---|---|---|
| GitHub (публичный репозиторий) | `gh api`, `gh run list`, `gh pr list` | `gh` авторизован владельцем; статистика Traffic доступна только владельцу |
| Локально | `data/<канал>/runs/<месяц>_<сегмент>_v<N>/run.json` | файл на компьютере человека |

Сторонних сервисов нет. Секреты здесь не нужны.

## 6. Что сознательно НЕ собираем

- **Посещения витрины.** Счётчик (например, Яндекс.Метрика) отправил бы данные посетителей стороннему сервису и потребовал бы внешнего скрипта на странице, а страница сейчас без внешних ресурсов (на это есть защитный тест). Решение человека, 2026-10-30; пересмотреть, если появится трафик и нужда в нём.
- **Телеметрию самого продукта.** Ничего из запусков у людей наружу не отправляется: ни расход квоты, ни названия видео, ни комментарии, ни настройки канала. Решение человека, 2026-10-30.
- Содержимое каналов, комментарии, ключи, названия и описания видео.
