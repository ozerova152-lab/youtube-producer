# Как получить ключ YouTube Data API

Инструкция для человека, который ни разу не работал с Google Cloud. Ключ бесплатный: квота 10 000 единиц в день, типичному месяцу хватает с запасом. Без ключа тоже можно начать: см. «Без ключа: импорт из файла» в [README](../README.md).

**Про названия кнопок.** Google Cloud Console время от времени переименовывает пункты и переставляет их. Английские названия ниже сверены с документацией Google ([страница про ключи API](https://docs.cloud.google.com/docs/authentication/api-keys) и [быстрый старт YouTube Data API](https://developers.google.com/youtube/v3/getting-started)). Русские названия (интерфейс на русском) по документации сверить не удалось: они даны по памяти и могут отличаться. Если не нашли пункт, ориентируйтесь на английский вариант или переключите язык аккаунта Google на English.

## Главные подводные камни

- **Банковская карта не нужна.** Для YouTube Data API ключ создаётся без карты. Если Google просит карту, вы свернули не туда.
- **Кнопку «Start free» / «Активировать бесплатно» не нажимайте.** Она предлагает пробный платный период Google Cloud и просит карту. Для нашего ключа она не нужна: достаточно войти в консоль и пользоваться бесплатной квотой API.
- **Ограничьте ключ.** В блоке «API restrictions» выберите «Restrict key» и отметьте только **YouTube Data API v3**.
- **«Application restrictions» оставьте в положении «None».** Если поставить «IP addresses», ключ перестанет работать, потому что у домашнего интернета IP-адрес меняется. «Websites» и приложения Android/iOS тоже не подходят: скрипт запускается у вас на компьютере.
- **Ключ в чат не вставляйте.** Ни в чат с агентом, ни в коммит, ни в скриншот. Он лежит только в файле `.env`.

## Шаг 1. Откройте консоль и создайте проект

1. Откройте [Google Cloud Console](https://console.cloud.google.com/) и войдите в аккаунт Google.
2. Если появится окно с условиями использования, согласитесь. Предложение попробовать платный период («Start free» / «Активировать бесплатно») пропустите.
3. Вверху страницы нажмите на выбор проекта (рядом с логотипом Google Cloud) и выберите «New project» («Новый проект»).
4. Назовите проект как угодно, например `youtube-producer`, и нажмите «Create» («Создать»).
5. Убедитесь, что вверху выбран именно этот проект.

## Шаг 2. Включите YouTube Data API v3

1. В меню слева откройте «APIs & Services» («API и сервисы») → «Library» («Библиотека»).
2. Найдите **YouTube Data API v3** и откройте её страницу.
3. Нажмите «Enable» («Включить»). Проверка: API появилась в списке «Enabled APIs» («Включённые API»).

## Шаг 3. Создайте ключ

1. «APIs & Services» → «Credentials» («Учётные данные»).
2. Нажмите «Create credentials» («Создать учётные данные») → «API key» («Ключ API»).
3. Консоль может сразу предложить ограничения при создании (в документации Google сказано, что хотя бы одно ограничение она требует): выберите «Restrict key» и отметьте YouTube Data API v3, как в шаге 4. Если не предложила, ограничите ключ следующим шагом.
4. Нажмите «Create» («Создать»). В окне «API key created» показан ключ. Скопируйте его, но никому не показывайте. Потом его можно открыть снова: «Credentials» → имя ключа.

## Шаг 4. Ограничьте ключ

Ограничение защищает вас: если ключ утечёт, им нельзя будет пользоваться для чужих сервисов Google.

1. «Credentials» → нажмите на имя вашего ключа.
2. Блок «Application restrictions» («Ограничения для приложений»): оставьте **None** («Нет»).
3. Блок «API restrictions» («Ограничения API»): выберите «Restrict key» («Ограничить ключ»).
4. В списке отметьте только **YouTube Data API v3**. Если её нет в списке, вы не включили её в шаге 2.
5. Нажмите «Save» («Сохранить»). Изменения могут вступить в силу не сразу: до пары минут.

## Шаг 5. Положите ключ в `.env`

Ключ лежит только в локальном файле `.env` в корне проекта. Он не попадает в git (внесён в `.gitignore`).

Откройте проект в Claude Code. Команды ниже начинаются с `!`: это значит «запустить в этом же окне Claude Code» (оболочка выполнит команду сама, агент ничего не придумывает). Без `!` их можно вводить в обычном терминале в папке проекта.

Сначала посмотрите, где вы и нет ли уже `.env`:

```
! pwd
! ls -a /путь/к/youtube-producer
```

Создайте файл из шаблона, подставив свой полный путь вместо `/путь/к/youtube-producer` (его показал `pwd`):

```
! cp /путь/к/youtube-producer/.env.example /путь/к/youtube-producer/.env
```

Проверьте, что файл создан (должна напечататься строка с именем файла, без содержимого):

```
! ls -l /путь/к/youtube-producer/.env
```

Теперь откройте `.env` в любом текстовом редакторе и впишите строку:

```
YOUTUBE_API_KEY=ваш_ключ
```

Подставьте свой ключ вместо `ваш_ключ`, без кавычек и пробелов. **Не вставляйте ключ в чат и не пишите его в команде с `!`:** всё, что набрано в окне Claude Code, попадает в разговор. Агент `.env` не читает и ключ не показывает.

Если ключ где-то засветился (чат, коммит, скриншот), перевыпустите его в Google Cloud: «Credentials» → имя ключа → создайте новый и удалите старый. Просто стереть упоминание недостаточно.

## Если залётов получилось слишком много

Порог «залёта» задаётся в `settings.yaml` вашего канала (`data/<канал>/settings.yaml`) параметром `views_multiplier`: во сколько раз видео должно обогнать обычные просмотры канала. По умолчанию 3. Если в списке слишком много видео, поднимите значение, например с 3 до 7.

- Файл правит **человек**, а не агент: откройте `settings.yaml` сами, поменяйте число и напишите агенту «готово».
- Пересчёт идёт по уже собранным данным, поэтому квота не тратится: команды `virals` и `report` просто запускаются заново:

```
! /путь/к/youtube-producer/.venv/bin/produce --channel /путь/к/youtube-producer/data/<канал> virals
! /путь/к/youtube-producer/.venv/bin/produce --channel /путь/к/youtube-producer/data/<канал> report
```

## Если ключ не работает

- Сообщение про отказ (`403`) или «API не включена»: вернитесь к шагу 2 и проверьте, что включена именно YouTube Data API v3 в том же проекте, где создан ключ.
- Сообщение про ограничения: проверьте шаг 4. «Application restrictions» должны быть None, в «API restrictions» должна быть отмечена YouTube Data API v3.
- Только что изменили настройки: подождите пару минут.
- «Quota exceeded»: дневная квота кончилась, она обнуляется раз в сутки.
