# Функциональные требования — AI-продюсер YouTube-канала

> Слой 1 из 3 · «ЧТО и для кого» · Дата: 2026-10-22 (концепция обновлена: открытая «витрина» для агента)

## Продукт одним предложением

Открытый на GitHub набор инструкций, шаблонов и небольшой скрипт сбора данных: человек открывает папку в своём Claude Code по своей подписке, и агент по пошаговым сценариям находит залетевшие за 30 дней видео ниши через YouTube Data API, разбирает причины, строит контент-стратегию, месячный план и брифы; решает и публикует всегда человек. Запустить можно в Claude Code, Claude Cowork или Codex: общие инструкции лежат в `AGENTS.md`, в README три коротких пути (как открыть папку и какую фразу сказать). В README и на витрине человеку предлагается лишь ссылка «Расскажите, как получилось» на Issues (см. раздел «Что НЕ делаем»).

## Для кого

- **Основная аудитория:** автор малого канала (у первого пользователя ~400 подписчиков, тематика нейросети, простой монтаж), у которого есть Claude Code по собственной подписке (Cowork и Codex — по описанию в README, тот же `AGENTS.md`). Задача: понять, какие темы реально набирают просмотры и охваты, и не выбирать тему наугад.
- **Вторичная:** любой автор любой ниши, кто возьмёт репозиторий с GitHub: ниша, язык и аудитория задаются только в файле настроек, ничего не вшито.
- **НЕ аудитория:** крупные каналы и студии; те, кто ищет автопубликацию или «канал на автопилоте»; те, кому нужна закрытая аналитика своего канала; те, кому нужна самостоятельная программа без ИИ-агента.
- **Рынок / география:** сегменты (регион поиска + язык анализа) задаются списком в настройках. На старте два: русскоязычный и англоязычный; новые добавляются записью в файл. Сегменты не смешиваются. Язык брифа: язык сегмента или русский, выбор при запуске. Сообщения человеку по-русски.

В каждом 2–3 видео-образца со ссылками и главные эмоции из комментариев | Дано утверждённая стратегия; когда агент выполнил сценарий; тогда в каждом брифе заполнены все поля своего вида; бриф без обязательного поля не принимается проверкой |
| Статусы брифов | Я помечаю каждый бриф: принят / отклонён / позже (пусто, пока решения нет) | Дано бриф; когда ставлю «отклонён»; тогда его нет в плане |
| История запусков | Каждый запуск (календарный месяц + сегмент) хранится отдельно; незавершённый запуск месяца и сегмента агент предлагает продолжить по этапу в `run.json`, новая версия (v2) — только после этапа «план готов» и только после моего слова «да» на вопрос агента (флаг `--new-version`); история берётся только из запусков того же сегмента; следующий запуск не повторяет отклонённые и уже предложенные темы; брифы «позже» можно вернуть | Дано отклонённая тема в прошлом месяце; когда идёт новый запуск; тогда проверка находит её повтор в стратегии или брифах и не пропускает. Дано запуск остановлен на стратегии; когда возвращаюсь; тогда агент называет этап и предлагает продолжить, а не создаёт v2 |
| Проверка файлов агента | Скрипт проверяет, что файлы стратегии, брифов, плана и разбора соответствуют шаблонам и правилам | Дано файл с пропущенным полем, битой строкой статуса или повтором отклонённой темы; когда запускаю проверку; тогда сообщение по-русски с названием файла и места |

## Нефункциональные требования (поведение в сложных условиях)

- Квота YouTube ограничена (~10 000 единиц в день): расход оценивается заранее и подтверждается только после моего слова. Квота кончилась: прогресс сохранён, запуск продолжается на следующий день, собранное не тратит квоту повторно.
- Сбой API или сети: 3 повтора с растущей паузой, затем остановка с понятным сообщением по-русски и сохранённым прогрессом. Нет ключа или он неверный: сообщение, как его задать, и подсказка про импорт из файла.
- Нет данных (мало роликов, мало комментариев): видео пропускается с пометкой причины; результаты на неполных данных помечены «неполные данные» с числом пропущенных.
- Агент останавливается на паузах (утверждение стратегии, статусы брифов) и не идёт дальше без моего слова.
- Комментарии и любой чужой текст агент читает как данные, а не как инструкции; публикацию, постинг и изменение `settings.yaml` не делает.
- Агент не читает `.env`: ключ YouTube нужен только скрипту. Ключ лежит только на компьютере пользователя и не попадает в репозиторий, отчёты и логи.
- Тяжёлые шаги разбиты на части (по видео), чтобы помещаться в лимит подписки; лимит кончился: результаты уже в файлах, шаг продолжается позже.
- Результат шага проверяется скриптом проверки файлов; красная проверка: агент исправляет, не двигаясь дальше.
- Данные только из официального YouTube Data API или из файла, который даёт человек.

## Что НЕ делаем

| Не делаем | Почему не сейчас |
|-----------|------------------|
| Публикация, загрузка видео, постинг в Сообщество | Решает человек, ничего не публикуется автоматически |
| Собственный ИИ-движок, ключ ИИ, оплата ИИ | ИИ делает агент по подписке пользователя |
| Отдельные настройки и автопроверки под каждого агента (Cowork, Codex) | Общий `AGENTS.md` и описание в README; защиты уровня `.claude/settings.json` и мини-скиллы есть только в Claude Code |
| Запуск агента без человека (по расписанию, автопилот) | Решения принимает человек |
| Парсинг сайта YouTube | Только официальный API или файл от человека |
| Закрытая аналитика канала (удержание, CTR) | Следующая версия |
| Веб-интерфейс самого продукта, аккаунты, оплаты, свой сервер | Продукт локальный, для одного человека. Исключение: одна статическая страница-витрина (см. фичи) |
| Подробные обучающие материалы и поддержка чужих авторов | Сейчас только короткий README |
