## Бюджет и ограничения по инструментам

| Что | Значение |
|-----|----------|
| Потолок в месяц | до 1 000 ₽ |
| Чем платить | российская или зарубежная виртуальная карта |
| Разовые траты | не нужны (всё лежит на GitHub, домена нет) |

**Зафиксировано человеком** (не пересматривается без его слова):

- Ничего не публиковать самой: программа не пишет в YouTube.
- Новый платный сервис, тариф или пакет — только с отдельного «да» человека. Бесплатные варианты показываются первыми с ценой выбора.
- Подписка Claude Pro есть (через неё работает Claude Code), отдельного API-ключа нейросети пока нет; ключ YouTube Data API пользователь создаёт сам.
- **ИИ — платный Claude API, выбран человеком 2026-10-22 («да» на платное в пределах потолка).** Ему показали бесплатные варианты и цену выбора: Gemini API (бесплатный тариф: лимиты запросов, доступность из РФ не подтверждена, данные бесплатного тарифа могут идти на улучшение продуктов Google), Claude Code по подписке Pro (не годится: чужие авторы не смогут запускать, программа не самостоятельная), локальная модель (слабее по-русски, нужен мощный компьютер). Gemini остаётся запасным провайдером, переключается в настройках.

**Открыто:** приём карты провайдером Claude API при пополнении (есть российская и зарубежная виртуальная карты) — проверить при первом пополнении; не принимает — переключить провайдера на Gemini.

## Компоненты продукта

| Компонент | Инструмент | Цена | Зачем в этом продукте |
|-----------|-----------|------|----------------------|
| Язык и среда | Python 3.12+ | 0 ₽ | Самый массовый язык для работы с данными и API, ИИ пишет на нём увереннее всего |
| Ядро (слой логики) | Python-пакет без привязки к интерфейсу. Модули: настройки; оценка квоты и подтверждение; сбор данных и мои результаты; поиск залётов; разбор причин; анализ ниши и кандидаты в конкуренты; стратегия; план; брифы с упаковкой; статусы; хранение и история запусков (не повторять темы) | 0 ₽ | Вся логика продукта живёт здесь, интерфейсы только вызывают её |
| Интерфейс сейчас | Терминальные команды (Typer) | 0 ₽ | Пошаговые команды дают паузы и «да» из слоя 1; сайт не нужен |
| YouTube-клиент | Официальный клиент YouTube Data API v3 | 0 ₽ (10 000 единиц квоты в день) | Единственный источник данных |
| ИИ-компонент | Claude API, малая модель (claude-haiku-5-5, идентификатор сверить с официальным списком), за тонким слоем «провайдер ИИ» | ~5–25 ₽ за месячный запуск (оценка, см. ниже) | Разбор комментариев, стратегия, брифы; провайдер меняется в настройках |
| Хранение данных | Файлы в папке данных: настройки в YAML, собранное в JSON, стратегия, брифы и план в Markdown | 0 ₽ | Читаются и правятся руками, статус брифа — одна строка; база не нужна |

Не берём: сайт-фронтенд, сервер-бэкенд, базу данных, авторизацию, платежи, почту, файловое хранилище, очередь: у локальной программы для одного человека для них нет причины. Ответы API кэшируются просто файлами внутри запуска (см. схему), отдельного кэш-сервиса нет.

**Где кончается бесплатное:** квота YouTube API 10 000 единиц в день (поиск 100, видео и комментарии по 1); при превышении запуск сохраняет прогресс и продолжается завтра. ИИ платный по потреблению. Расчёт на типичный запуск: ~20 залётов × 100 комментариев ≈ 80 тыс. входных токенов, плюс стратегия и брифы ≈ 120 тыс. входных и 40 тыс. выходных; при $0,10 / $0,50 за миллион это около $0,04 (≈ 4 ₽), с запасом на перегенерации ×5 — до ~25 ₽. Пополнение баланса разовое, минимум порядка $5 (≈ 400–500 ₽), хватает на многие запуски и укладывается в потолок; цены Anthropic подтвердить на сайте до пополнения. Файлы кончаются при сотнях запусков или многопользовательском доступе.

**Хостинг / развёртывание:** хостинга нет; код на GitHub, запуск на компьютере пользователя · **Домен:** нет

## Запланированные расширения (не отказ)

Ядро отделено от интерфейса, поэтому позже можно добавить без переписывания логики: окно-приложение для компьютера; сайт или бот (тогда понадобятся хостинг, база данных, регистрация и оплата: добавляются отдельным слоем). В первую версию не входят.

## Схема данных (из сущностей слоя 1: файлы вместо таблиц)

Папка данных (в `.gitignore`, путь задаётся в настройках, по умолчанию `data/<канал>/`). Пример настроек лежит в репозитории отдельно (`examples/`).

| Сущность (файл) | Ключевые поля | Связи |
|-----------------|--------------|-------|
| Настройки и Сегмент (`settings.yaml`) | ниша, аудитория, сегменты (регион + язык; сегмент задаётся записью в этом файле), ключевые слова, каналы-конкуренты, мой канал, пороги, пределы частоты, провайдер ИИ | один файл на канал |
| Запуск (`runs/<месяц>_<сегмент>_v<N>/run.json`) | месяц, сегмент, язык брифа, версия, этап, расход квоты, список неполных данных | принадлежит каналу; хранит остальное |
| Видео, Канал, Комментарий (`cache/videos.json`, `channels.json`, `comments.json`) | видео: id, канал, просмотры, лайки, число комментариев, дата; канал: недавние ролики, норма; комментарий: id, видео, текст, лайки | кэш ответов API внутри запуска: после сбоя или квоты уже собранное не запрашивается повторно |
| Залёт и Разбор (`virals.json`) | id видео, просмотры, норма, вовлечённость, эмоции и темы, образцы | ссылается на Видео из этого запуска |
| Стратегия (`strategy.md`) | вводные, баланс форматов, частота, статус «черновик / утверждена» | один на запуск |
| Бриф (`briefs/<id>.md`) | вид (длинное / Shorts / пост), статус (принят / отклонён / позже), структура вида, упаковка, образцы | ссылается на Залёты; принадлежит запуску |
| План (`plan.md`) | список принятых брифов, месяц | собирается из Брифов запуска |
| Кандидат в конкуренты (`candidates.md`) | канал, причина | в настройки добавляет только человек |

История запусков = папки `runs/`; повторный запуск в том же месяце создаёт новую версию.

## Внешние интеграции

| Сервис | Что делает для продукта | При сбое |
|--------|------------------------|----------|
| YouTube Data API | Поиск видео, статистика каналов, комментарии | 3 повтора с растущей паузой; квота кончилась — сохранить прогресс, продолжить завтра; нет или неверный ключ — понятное сообщение без запросов |
| Claude API (через слой «провайдер ИИ») | Разбор комментариев, стратегия, брифы | 3 повтора; затем остановка с сохранённым прогрессом; нет ключа или баланса — понятное сообщение, сбор данных не теряется |

## Надёжность файлов

Запись файлов идёт через временный файл с переименованием, чтобы обрыв не оставлял битый JSON. Если файл повреждён или отредактирован вручную с ошибкой формата (строка статуса брифа, структура стратегии), программа не падает: называет файл и место ошибки по-русски и ничего не перезаписывает.

## Секреты и ключи

Ключи YouTube и ИИ лежат только в локальном файле `.env` на компьютере пользователя, который указан в `.gitignore`; в репозитории лежит `.env.example` без значений. Ключи не пишутся в код, отчёты, логи и файлы данных. У ключа ИИ на стороне провайдера выставляется лимит трат. Тексты публичных комментариев уходят ИИ-провайдеру на разбор; личные данные пользователя туда не передаются, тексты в логи не пишутся.
