## Описание

Клиент YouTube Data API v3 (официальный клиент Google): поиск за 30 дней по словам сегмента (регион и язык из сегмента), ролики конкурентов, последние ролики найденных авторов. Квота: поиск 100 единиц, остальное по 1; последние ролики автора брать через список загрузок канала, а не поиском. Оценка считается до запросов и включает верхнюю границу на комментарии залётов (до 20 видео); сами комментарии качает `produce comments` (T08). Двухшаговая схема: `produce collect` без флага только оценивает, `produce collect --confirm` собирает; `--confirm` ставит только человек или агент после его слова. Кэш: `cache/videos.json`, `channels.json`. Кассеты — в `examples/demo/` формата pytest-recording; пока нет ключа, собрать вручную по формату официальных ответов, позже заменить настоящими записями; ключа в кассетах быть не должно. Читай 01-functional-requirements.md (Оценка квоты и сбор данных).
