## Описание

Подтверждено человеком (2026-10-30): порядок пунктов «залётные ролики, разбор, ниша, конкуренты, стратегия, брифы и сценарии, план»; даты «начало запуска» и «последний сбор»; имя файла `00-overview.md` (ASCII в имени, внутри по-русски). Имена остальных файлов запуска и имя папки **не меняются** (переименование отложено как слишком рискованное: старые запуски, история месяцев, версии внутри месяца).

Что сделать:
- новый модуль ядра (например `src/produce/core/overview.py`) строит текст обзора из состояния папки запуска и `run.json`; запись через `write_text_atomic`; слой интерфейса только вызывает его;
- в `run.json` два новых поля с датами (`started_on`, `collected_on`), старые запуски остаются читаемыми без них;
- обзор обновляется после команд `start`, `collect`, `import`, `comments`, `virals`, `report`, зелёного `check-files` и `later`, плюс новая команда `produce overview`;
- тексты в обзоре берутся из спеки (экран «Обзор запуска» в `docs/spec/04-user-flows.md`): сначала сверься со спекой, потом код (правило проекта);
- обновить `AGENTS.md` (правило «Как агент отчитывается после каждого шага», часть 4), `playbooks/00-month.md`, `README.md`; **до выполнения задачи `AGENTS.md` и сценарии на `00-overview.md` не ссылаются**, чтобы агент не отправлял человека к несуществующему файлу.

Ограничения: файл производный и не правится руками (в шапке об этом сказано); агент его не пишет; ключ, комментарии и названия видео в него не попадают; ничего не публикуется и не пушится.

Оценка: около половины рабочего дня, один присест.
