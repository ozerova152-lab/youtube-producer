## Описание

Сценарий `playbooks/07-history.md`: агент читает папки `runs/` канала и учитывает прошлые темы. Проверка повторов — в `check-files` по списку тем отклонённых и уже предложенных брифов (по названию и видео-источнику), а не только текстом инструкции. `produce later` показывает «позже» прошлых запусков и копирует выбранные. Старые запуски не меняются.
