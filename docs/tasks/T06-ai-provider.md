## Описание

Небольшой интерфейс провайдера в ядре (запрос → ответ в заданном формате), реализация Claude через официальный SDK Anthropic (модель из `ai.model`, ключ из `.env`, проверить имя модели в официальном списке) и фиксированный провайдер для тестов с режимами сбоев. Запросы к настоящему Claude только при `--real`; тесты ходят в сеть не могут. Тексты комментариев в логи не писать. Второй настоящий провайдер (Gemini) в этот план не входит.
