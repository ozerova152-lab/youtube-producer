## Описание

Клиент YouTube Data API v3 (официальный клиент Google) в ядре; поиск видео за 30 дней по словам сегмента (регион и язык из сегмента), ролики конкурентов, последние ролики найденных авторов, комментарии. Стоимость в квоте: поиск 100 единиц, видео/каналы/комментарии по 1: последние ролики автора брать через список загрузок канала (дешевле поиска), а не поиском. Оценка квоты считается до запросов и включает верхнюю границу на комментарии залётов (до 20 видео, по 1 единице; сами комментарии качает шаг `analyze`, T07); без «да» (вопрос; в тестах `--yes`) запросов нет. Кэш: `cache/videos.json`, `channels.json`. Отчёт: `produce report` собирает `report.md` из секций, которые добавляют следующие задачи (первая секция «Собрано»). Кассеты для тестов — в `examples/demo/` формата pytest-recording; пока нет ключа, их можно собрать вручную по формату официальных ответов API, позже заменить настоящими записями. В кассетах ключа быть не должно. Читай 01-functional-requirements.md (Сбор данных, Оценка квоты) и 02-tech-architecture.md (интеграции).
