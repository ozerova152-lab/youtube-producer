## Описание

Обернуть вызовы YouTube в повторы (3 попытки, растущая пауза), распознавать «квота исчерпана», сохранять прогресс в `run.json` и кэше, писать пометку неполных данных в `run.json` и отчёт. Паузу в тестах подменять.
