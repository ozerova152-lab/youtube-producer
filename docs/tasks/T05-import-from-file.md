## Описание

Команда `produce import <файл>` кладёт данные в кэш текущего запуска в формате T03. Формат и пример: `docs/import-format.md` и `examples/demo/import.csv` (или json). Комментарии в файле необязательны. Источники данных для файла (ручная выгрузка, сторонние сервисы) в документе формата только перечисляются, без привязки.
