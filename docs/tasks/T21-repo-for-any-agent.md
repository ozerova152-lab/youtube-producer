## Описание

Сейчас главный файл инструкций один, `CLAUDE.md`, а Codex и Cowork описаны в README как «дайте ссылку и попросите прочитать `CLAUDE.md`». Проверка «глазами новичка» (2026-10-30, свежая копия репозитория во временной папке) показала: установка, `make check` и демо-запуск работают, но README не даёт быстрого старта, не объясняет слова, не говорит, что делать при ошибках, и не различает три агента. Решение человека: общий файл `AGENTS.md` как основа, `CLAUDE.md` ссылается на него без дублей, в README три коротких пути.

Спека уже обновлена (слои 1 и 2, поток 1 в `04-user-flows.md`) и снимает прежний запрет на `AGENTS.md`. Задача — привести репозиторий в соответствие.

Что сделать:
- создать `AGENTS.md` из содержимого `CLAUDE.md` (части A и B), в `CLAUDE.md` оставить подключение `@AGENTS.md` и только Claude-специфичное; везде, где `CLAUDE.md` назван «единственным» или «главным», поправить ссылки (README, playbooks, `docs/`, комментарии, тесты);
- переписать начало README: быстрый старт из трёх шагов, три пути, раздел «Безопасность» выше путей для Cowork и Codex, демо с комментариями, «Если что-то не получилось», глоссарий, оценка времени и подписки только по измеренному;
- разделить установку: для пользователя без Chromium, для разработчика полная (решить и записать в журнал, как назвать цель в `Makefile` и где остаётся `make setup`); обновить `docs/dev/setup.md`;
- добавить бонус-скиллы `/start-month`, `/continue-month`, `/demo`, `/setup-check` в `.claude/skills/` с пометкой «Только Claude Code»; они не обязательны для запуска;
- изменить тесты: `tests/test_agent_instructions.py` (сейчас требует отсутствия `AGENTS.md`) и другие, читающие `CLAUDE.md`, переведены на пару `AGENTS.md` + `CLAUDE.md`; изменение сознательное, смотри дифф.

Ограничения и оговорки:
- Cowork и Codex сами не запускались; пометки «проверено / не проверено» не должны обещать больше, чем проверено. Названия кнопок и способы открытия папки в Cowork и Codex исполнитель сверяет с документацией, а не берёт по памяти.
- Размер большой (текст, Makefile, четыре мини-скилла, тесты). Если исполнитель упирается в предел, он останавливается и предлагает вынести бонус-скиллы в отдельную задачу, а не режет критерии молча.
- Адрес-заглушку репозитория в README не менять (решение человека).
- Ключи и `.env` не читать; `settings.yaml` не менять; личные данные (пути `/home/...`, имя пользователя, ID канала) в тексты не вставлять.
- Ничего не публикуется и не пушится.
