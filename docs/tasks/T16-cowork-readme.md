## Описание

Сейчас в README два способа: Claude Code и Codex (с пометкой «проверен лишь на базовом уровне»). Нужен третий для тех, у кого нет Claude Code, а есть Claude Cowork: скачать ZIP с GitHub, распаковать, открыть папку в Cowork и написать агенту, что делать. Раздел простой, для человека без опыта: шаги списком, без учебных материалов, в стиле существующего README.

Главное требование — честность. Мы не запускали проект в Claude Cowork и не знаем наверняка, что он умеет в вашей среде (запуск команд, Python, `make`, чтение `CLAUDE.md`). Поэтому раздел явно разделяет «проверено» и «не проверено» и не обещает того, что не проверено. Не выдумывать возможности и названия кнопок Cowork: если не уверены, писать «не проверено» или «посмотрите в интерфейсе сами».

Спека не меняется: задача идёт с `spec_sync: pending` (спека про Cowork пока молчит). После приёмки можно предложить донести способ в слой 1 («Публикация на GitHub»), но только с согласия человека. Витрина (`site/`) тоже не меняется: в слое 1 в её блоке «Как запустить» два способа; если третий нужен и там, это отдельное решение вместе со спекой.

Адрес репозитория в README пока заглушка (репозиторий не опубликован), шаг «скачать ZIP» нужно писать без привязки к конкретному адресу или с тем же адресом-заглушкой.
