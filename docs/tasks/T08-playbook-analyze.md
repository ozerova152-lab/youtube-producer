## Описание

Команда `produce comments` (оценка квоты, `--confirm` после слова человека, потом докачка только для залётов, `comments.json`). Сценарий `playbooks/02-analyze.md`: шаги, паузы, что читать, что писать, как вызывать `check-files`, как разбивать работу по видео (лимит подписки). Шаблон `templates/analysis.md`, образец `examples/demo/expected/analysis.md`. Команда `produce check-files` появляется здесь с проверкой analysis.md, следующие задачи расширяют её на свои файлы. Тексты комментариев в логи не писать. Критерии про язык и смысл скрипт не проверит, поэтому в задаче `review: human`.
