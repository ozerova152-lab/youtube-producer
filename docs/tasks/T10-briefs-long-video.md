## Описание

Один бриф — один файл `briefs/<id>.md` с единой структурой по виду (вид и статус в шапке файла), потому что позже из них делают промпты для нейровидео. Валидатор обязательных полей по виду отдельно от ИИ; дальше виды Shorts и пост добавит T11 в тот же механизм. Образцы выбираются из залётов запуска. Читай 01-functional-requirements.md (Брифы, Упаковка).
