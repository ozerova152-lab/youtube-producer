## Описание

Главный сценарий месяца `playbooks/00-month.md` связывает остальные сценарии и паузы. README на русском. Отдельной поддержки Codex нет: в README только описание способа и честная пометка о базовой проверке. Настоящий прогон на ключе и подписке человек делает сам; в задачи он не входит. Лицензию выбирают при публикации на GitHub: в задачу не входит. Страница-витрина (`site/`, тест `tests/test_showcase.py`) собрана вне плана, в задачу входит только замена условного примера данными из `examples/demo/`; адрес репозитория и GitHub Pages — при публикации репозитория, не здесь. Список слов, считающихся «словом человека» («да», «готово», «запусти сбор»), задаётся в `playbooks/01-collect.md` (T07) и сверяется с `CLAUDE.md`.
