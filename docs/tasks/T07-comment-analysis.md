## Описание

Команда `produce analyze`: сначала оценка квоты и «да», затем докачка комментариев залётов (до 100 самых популярных на видео), затем разбор через провайдер ИИ (T06); секция «Разбор» в report.md. Результат пишется в запись залёта (`virals.json`, поле разбора). Образцы для брифов выбираются позже (T10).
