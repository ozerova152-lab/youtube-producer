## Описание

Читает папки `runs/` канала; ничего не пишет в старые запуски. Фильтр повторов работает в коде по списку тем отклонённых и уже предложенных брифов (по названию и видео-источнику), а не только текстом запроса к ИИ. Команда `produce later` показывает брифы «позже» прошлых запусков и копирует выбранные в текущий. Обе версии одного месяца считаются историей.
