## Описание

Обернуть вызовы YouTube в повторы (3 попытки, растущая пауза), распознавать ответ «квота исчерпана» и сохранять прогресс в `run.json` и кэше; пометку неполных данных писать в `run.json` и в отчёт. Паузу между повторами в тестах подменять, чтобы тесты шли быстро.
