# Если у вас только чат

[← К README](../README.md)

Бывает, что под рукой только обычный чат с ИИ: без терминала, без доступа к папке проекта. Проект работает и так, но по-другому, и честно скажем, чем это хуже. Статус этого режима — в [агентах](compatibility.md#статус); сценарий `playbooks/no-terminal.md` сверен с кодом автотестами.

**Как это устроено.** Откройте чат, дайте ему файл `AGENTS.md` (или вставьте текст) и напишите «запусти месяц». Агент сам поймёт, что запускать команды он не может, и один раз скажет об этом. Дальше он работает по данным, которые вы вставите в чат или приложите: таблица или файл в формате из [`docs/import-format.md`](import-format.md) (CSV, JSON или таблица из Google Sheets). Для каждого канала нужны 5–20 последних роликов, иначе нет «нормы» и ролики пропускаются.

**Чем отличается от обычного режима:**

- Сбор с YouTube по ключу недоступен. Ключ в чат вставлять не нужно (и не вставляйте: он должен оставаться только у вас). Данные приходят из файла.
- Агент считает залёты и ваши результаты вручную, по формулам из `playbooks/no-terminal.md`, поэтому каждое число он помечает «посчитано вручную, приблизительно» и показывает таблицу расчёта, которую можно проверить. За раз он берёт не больше 60 видео: больше пришлите частями.
- Агент ничего не сохраняет в файлы. Результаты (`strategy.md`, брифы, `plan.md`) приходят блоками с названиями файлов, а сохраняете их вы: скопировали блок и положили в папку запуска.
- Памяти о прошлых месяцах в чате нет: в новом месяце агент попросит вставить прошлые брифы со статусами «принят / отклонён / позже», чтобы не предложить заново отклонённые темы.
- Паузы остаются теми же: стратегию вы утверждаете словом «утверждена», статусы брифов называете в чате. Агент ничего не публикует.

Когда будет возможность, переходите на обычный режим с терминалом ([быстрый старт](../README.md#быстрый-старт)): он точнее, потому что цифры считает скрипт, и сам сохраняет файлы.
