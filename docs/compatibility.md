# Агенты: как запустить и что проверено

[← К README](../README.md)

## Подсказки по агентам

- **Claude Code.** Откройте терминал в папке проекта и запустите `claude`.
- **Claude Cowork.** Откройте папку проекта в приложении Claude Desktop.
- **Codex.** Откройте терминал в папке проекта и запустите `codex`.

## Как поставить агента

Если агента ещё нет на компьютере, установите его по официальной странице (страницы на английском; нужна подписка на агента):

- Claude Code: <https://code.claude.com/docs/en/setup>
- Claude Desktop (для Claude Cowork): <https://claude.com/download>
- Codex: <https://github.com/openai/codex>

## Статус

**Основной путь — Claude Code, проверен полностью.** Codex проверен на реальном канале (30.10.2026) от установки до брифов: установка, ключ, сбор данных, залёты, ниша и кандидаты, стратегия, брифы. Cowork мы не проверяли: используйте тот же `AGENTS.md` и пишите в [Issues](https://github.com/ozerova152-lab/youtube-producer/issues). Обычный чат без терминала (режим без терминала, сценарий `playbooks/no-terminal.md`, [как он устроен](chat-mode.md)) на реальном канале мы тоже не проверяли.

Для всех используется тот же `AGENTS.md`, отдельных настроек и мини-скиллов под другие агенты нет.

Только для Claude Code есть необязательный бонус: мини-скиллы `/start-month`, `/continue-month`, `/demo`, `/setup-check` (описаны в `CLAUDE.md`). Без них всё работает по фразам.

## Установка по ссылке

Путь «Установка одной фразой» (сообщение агенту из README и раздел «Установка по ссылке» в `AGENTS.md`) на реальной машине пока не прогоняли: он описан и сверен автотестами по тексту. Результаты прогона пишите в [Issues](https://github.com/ozerova152-lab/youtube-producer/issues).

## Обложки залётов (шаг 3б)

Агент смотрит картинки только по адресам `https://i.ytimg.com/`. Проверено только в Claude Code: он скачивает файл обложки и открывает его как картинку. На остальных агентах этот шаг пока не пробовали, результат неизвестен. Если агент не видит картинки или ссылок на обложки нет (старый кэш, импорт без обложек), он попросит положить файлы в `data/<канал>/runs/<запуск>/thumbs/` под именем `<id видео>.jpg` (подходят `.png` и `.webp`) и подождёт слова «готово»; можно сказать «пропустить», остальные шаги от этого не зависят. Скрипт картинки сам не скачивает, а `data/` и файлы `*.jpg`, `*.png`, `*.jpeg`, `*.webp` не попадают в git.

## Про ключ в других агентах

Запрет чтения `.env` в `.claude/settings.json` работает только в Claude Code. В Cowork и Codex ключ держится лишь на инструкции в `AGENTS.md`: не вставляйте ключ в чат и не включайте автоподтверждение команд (подробнее в [ограничениях и безопасности](limits-and-security.md)).
