# Сценарии (playbooks)

Пошаговые инструкции для агента: один файл на один шаг. Это обычные Markdown-файлы, их может прочитать любой агент. Места, работающие только в Claude Code (мини-скиллы `/check`, `/reset`), помечены «Только Claude Code».

Порядок шагов описан в `CLAUDE.md`. Главный сценарий — `00-month` («запусти месяц» и «продолжи месяц»): он связывает остальные сценарии `01-collect` … `07-history` и паузы между ними.

Сценарии: `00-month`, `01-collect`, `02-virals`, `03-analysis`, `04-niche`, `05-strategy`, `06-briefs-plan`, `07-history`.
