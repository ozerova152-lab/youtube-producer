# Сценарии (playbooks)

Пошаговые инструкции для агента: один файл на один шаг. Это обычные Markdown-файлы, их может прочитать любой агент. Места, работающие только в Claude Code (мини-скиллы `/check`, `/reset`), помечены «Только Claude Code».

Порядок шагов описан в `CLAUDE.md`. Готовы сценарии `01-collect`, `02-virals`, `03-analysis`, `04-niche`, `05-strategy` и `06-briefs-plan` и `07-history`, остальные появятся на этапе разработки:
`00-month`.
