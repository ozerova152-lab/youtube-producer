# Шаблоны (templates)

Образцы файлов, которые заполняет агент: разбор (`analysis.md`), ниша (`niche.md`), кандидаты (`candidates.md`), стратегия (`strategy.md`), брифы, месячный план (`plan.md`). Обычные Markdown-файлы. По ним скрипт проверяет файлы агента: `produce check-files`.

Готовы шаблоны `analysis.md`, `niche.md`, `candidates.md`, `strategy.md` и `brief-long.md`; остальные появятся на этапе разработки. Образцы заполненных файлов лежат в `examples/demo/expected/`.
