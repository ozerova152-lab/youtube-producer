# Шаблоны (templates)

Образцы файлов, которые заполняет агент: разбор (`analysis.md`), стратегия (`strategy.md`), брифы, месячный план (`plan.md`). Обычные Markdown-файлы. По ним скрипт проверяет файлы агента: `produce check-files`.

Готов шаблон `analysis.md`; остальные появятся на этапе разработки. Образцы заполненных файлов лежат в `examples/demo/expected/`.
