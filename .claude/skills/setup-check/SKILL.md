> Только Claude Code. Необязательный бонус.

Выполни проверки и покажи по строке на каждую: «есть / нет» и что сделать.

1. Python 3.12+: `python3 --version`. Старее или нет: поставить Python 3.12+ с модулем venv.
2. `make`: `make --version`. Нет: поставить `make`.
3. Виртуальное окружение: `test -x .venv/bin/produce`. Нет: выполнить `make setup`.
4. Файл ключа: **только** `test -f .env`, ответ «есть» или «нет»; если «нет», подскажи команду `make add-key` (запускает человек в обычном терминале). Содержимое `.env` не читай, не печатай и не проверяй (ни `cat`, ни `grep`, ни `Read`). Нет файла: ключ можно получить позже, начать можно с демо или импорта из файла (README).

Ключ нигде не показывай. Ничего не устанавливай и не меняй без слова человека.
